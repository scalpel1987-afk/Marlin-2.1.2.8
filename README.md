# Flsun QQ-S Pro Custom Firmware (Marlin 2.1.2.8)

Индивидуальная сборка стабильной прошивки **Marlin 2.1.2.8** для 3D-принтера **Flsun QQ-S Pro (Delta)**, адаптированная под использование кастомной современной платы управления и тихих драйверов.

---

## 🛠️ Аппаратная конфигурация (Hardware)
* **Принтер:** Flsun QQ-S Pro (Кинематика Delta)
* **Материнская плата:** Makerbase MKS Robin Nano v3.1 (Процессор STM32F407)
* **Шаговые драйверы:** TMC2209 в полноценном режиме **UART** (Токи настроены из меню принтера)
* **Дисплей:** MKS TS35 v2.0 (Графический цветной тач-интерфейс `TFT_LVGL_UI` с поддержкой физического энкодера)
* **Экран развернут на 180°** для удобного кастомного монтажа на корпус
* **Датчик уровня:** Стоковый съемный магнитный датчик автокалибровки Delta (`G33` / автоуровень `UBL`)
* **Беспроводной модуль:** MKS Robin WiFi (ESP-12S / ESP8266) с поддержкой управления из слайсера по Wi-Fi

---

## 📥 Инструкция по компиляции и прошивке (How to flash)

> 📌 **Примечание по архитектуре:** В файле `platformio.ini` и плагинах сборки для плат ревизий v3.0 и v3.1 используется единое общее окружение — **`mks_robin_nano_v3`**. Это программно правильно и полностью совместимо с платой v3.1.

1. Скачайте этот репозиторий архивом или склонируйте его.
2. Откройте папку в **VS Code** с установленным плагином **PlatformIO**.
3. Запустите сборку под окружение **`mks_robin_nano_v3`**.
4. Перейдите в скрытую папку `.pio/build/mks_robin_nano_v3/`.
5. Заберите готовый файл прошивки и подготовьте SD-карту (формат **FAT32**, кластер **4096 байт**):
   * Переименуйте файл бинарника строго в `Robin_nano_v3.bin` и положите в корень карты.
   * Положите папку `assets` (содержит шрифты и графику для экрана) в корень карты.
6. Вставьте карту в выключенный принтер и включите его. Обновление займет около 1-2 минут.

* Вручную устранены баги линковщика графического интерфейса Makerbase (`draw_dialog.cpp` и `draw_pause_message.cpp`) при выключенной дефолтной панели MarlinUI.
* Настроен автоматический вызов калибровочного экрана тачскрина при первом старте.
